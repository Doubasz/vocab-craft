# Credits

## JLPT vocabulary decks

`src/main/resources/vocabcraft/decks/jlpt_n1.json` … `jlpt_n5.json` are generated by
`tools/build_jlpt_decks.py` from:

- [jamsinclair/open-anki-jlpt-decks](https://github.com/jamsinclair/open-anki-jlpt-decks)
  (MIT License, © 2020 Jamie Sinclair), pinned at commit `1ad6673`
- which is based on the JLPT vocabulary lists by Jonathan Waller ([tanos.co.uk](http://www.tanos.co.uk/jlpt/))

There is no official JLPT vocabulary list since 2010; these lists are community estimates.
The license of the original tanos.co.uk lists has not been verified. Check it before
distributing the mod publicly.

## Item names

`src/main/resources/vocabcraft/items_vanilla.json` is generated by `tools/build_item_names.py` from
Minecraft 26.3's own `ja_jp` / `en_us` language files (© Mojang). Kana readings are added with
[pykakasi](https://codeberg.org/miurahr/pykakasi) (GPL-3.0, used only as a build tool, not shipped)
plus hand-checked fixes. Bundling these translations is fine for personal use. To publish the mod,
read them from the client's language files at runtime instead.

`items_curated.json` is written by hand.
